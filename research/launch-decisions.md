# Launch component decisions

Checked 2026-10-09 against private active specification revision 1.2. This finishes the component-wide decision table for G1; it does not award G1 or later gates. [workflows.md](workflows.md) provides the ten priorities, concrete input/output examples, source scopes and uncertainty. [reuse.md](reuse.md) records engine code audits; [artifacts.json](artifacts.json) records exact model pins. Decisions below are implementation choices supported by inspected source. Admission still requires integrated acceptance evidence.

## Corresponding source and runtime pins

Installed `wasm-vips` 0.0.19 is published from npm `gitHead` `49ac4378f2df80e38f45491abeeac9b86dddbedd`. Its inspected [build.sh](https://github.com/kleisauke/wasm-vips/blob/49ac4378f2df80e38f45491abeeac9b86dddbedd/build.sh) and [Dockerfile](https://github.com/kleisauke/wasm-vips/blob/49ac4378f2df80e38f45491abeeac9b86dddbedd/Dockerfile) match the installed `versions.json` dependency versions and Emscripten 6.0.10. The earlier audit's source head `4ea2b9769a1179735b61ce9cb97176a2c8366674` contains newer glib/expat/heif/png inputs and is not the correct release build-input pin. Use the published pin for source correspondence. The source fetches some patch branches dynamically; archive and hash the exact patch/source inputs before claiming a reproducible rebuild.

`@img/sharp-libvips-linux-x64` 1.3.4 has npm `gitHead` and dereferenced v1.3.4 tag `ebb95f8add54eee8bed840e3fb587e4cbec857d7`. It distributes libvips 8.18.7 and compiled dependencies under LGPL-3.0-or-later/mixed terms, separately from Sharp's Apache-2.0 wrapper. Its [posix build](https://github.com/lovell/sharp-libvips/blob/ebb95f8add54eee8bed840e3fb587e4cbec857d7/build/posix.sh), [Linux x64 container](https://github.com/lovell/sharp-libvips/blob/ebb95f8add54eee8bed840e3fb587e4cbec857d7/platforms/linux-x64/Dockerfile) and actual `versions.json` identify source inputs. A repository link alone does not prove retained source archives or a tested replacement/relink path.

## Settled scope and remaining prerequisites

Original software remains Apache-2.0 and original catalog data CC0. Rare UI source retains MIT + Commons Clause + attribution; Animate UI retains MIT + Commons Clause. Owner approval covers use in this app under those terms; it does not relicense copied components. Local personal/commercial processing remains free. A later vanilla remake must preserve existing notices until copied code is replaced independently.

Art retains Effect.app as its reference. GPUI desktop, generation, managed inference/billing, self-hosted HTTP compatibility and other conditional capabilities remain later requirements. Rust remains conditional on a measured bottleneck or substantial architectural benefit. The launch keeps local image processing, preserved originals, approved model artifacts and the $0 additional infrastructure constraint.

G2 still needs actual phone measurements and the prescribed human quality evaluation. Numerical budgets/tolerances and winning profiles remain unresolved evidence prerequisites. G3-G7 need integrated interface, correction/manipulation, batch, agent, destination, offline, privacy, package and public-configuration checks. The preparation above does not redefine or defer a required failing check.
